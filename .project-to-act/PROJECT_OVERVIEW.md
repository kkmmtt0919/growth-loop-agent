- 细化入口：只有在需要查看历史、路线或成长统计时才进入二级页面；二级页面允许局部滚动。

## 项目目标

- 通过微信服务号与小程序，为个人用户建立“计划—行动—记录—结算—复盘—校准”的每日自我提升闭环。
- MVP 用户可在 30 秒内记录行动，系统用可解释规则生成 XP/积分，并用 7/28 天证据评估进步。
- 主动提醒严格受微信能力、用户授权、免打扰设置和频率上限约束。

## 范围

### 包含

- 个人目标、日程、待办、学习记录、运动/生活/休息行动、日/周复盘。
- XP 与成长积分双账本、等级、用户自定义奖励和温和连续机制。
- 证据驱动的成长评估、受控 Agent 工具调用与可撤销写操作。
- C 端微信服务号对话入口、小程序工作台和必要运营后台。

### 非目标

- 临床心理干预、未成年人监督、企业绩效考核。
- 公开排行榜、付费积分、陌生人社交和无限制主动推送。
- MVP 阶段的全平台日历/知识库集成和全自动人生规划。

## 技术路线与关键约束

- 推荐“已认证服务号 + 原生微信小程序 + 独立后端”的混合形态。
- 模型负责理解、建议和结构化提取；规则引擎负责 XP、积分和余额；所有写操作经受控工具完成。
- 微信 webhook 必须快速验签/去重/应答，耗时 Agent 推理异步执行。
- 提醒必须同时满足业务偏好和微信侧用户授权，不承诺无限主动触达。

## 数据与安全边界

- 数据分类：个人目标、日程、学习内容和复盘属于个人敏感业务数据；微信标识、授权凭证和消息回调受严格访问控制。
- 敏感信息处理：只记录脱敏摘要、证据 ID 和受控位置，不粘贴原始敏感数据。
- 用户拥有查看、更正、导出、暂停记忆和删除数据的入口；分析数据默认去标识化。
